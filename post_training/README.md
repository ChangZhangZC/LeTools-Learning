# RL Post-training (reserved)

This directory is reserved for reinforcement learning on top of
LeTools imitation-learning baselines, including RL100 DP-2D.

Planned scope: offline RL, critic/value estimation, dynamics models,
and PPO or other conservative post-training. No RL post-training
algorithm is added here by the present baseline reorganization.

Baseline policy code lives under kuavo_model/rl100_dp_2d/.
Do not copy the original RL100 actor or BC trainer here.
